# 固定表格底部分页栏解决方案

## 问题描述

在使用 Vue + Ant Design Vue 的 BasicTable 组件时，当表格数据较多时，分页栏会随着表格内容一起滚动，需要滚动到页面最底部才能看到分页栏，影响用户体验。

### 期望效果
- 表格内容区域可以滚动
- 分页栏始终固定在表格底部可见位置
- 无需滚动到最底部即可进行分页操作

## 解决方案

通过配置 BasicTable 组件的 `scroll.y` 参数，设置表格内容区域的固定高度。

### 核心配置

```javascript
const [registerTable] = useTable({
  // ... 其他配置
  scroll: {
    x: 1200,  // 横向滚动宽度（可选）
    y: 'calc(100vh - 300px)',  // 关键配置：固定内容区域高度
  },
  // ...
});
```

## 技术原理

### scroll 参数说明

| 参数 | 类型 | 说明 |
|------|------|------|
| scroll.x | number \| string | 设置横向滚动，可设置为像素值或百分比 |
| scroll.y | number \| string | 设置纵向滚动，**固定表格内容区域高度** |

### 工作原理

1. **不设置 scroll.y**：
   - 表格高度由内容撑开
   - 整个表格（包括分页栏）作为一个整体滚动
   - 数据多时需要滚动到底部才能看到分页栏

2. **设置 scroll.y**：
   - 表格内容区域变成固定高度的滚动容器
   - 只有内容区域参与滚动
   - 表头和分页栏固定位置，不参与滚动

### 高度计算说明

使用 `calc(100vh - 300px)` 动态计算高度：

- `100vh`：浏览器视口高度的 100%
- `300px`：页面其他元素占用的高度总和
  - 顶部导航栏：约 64px
  - 查询表单区域：约 100px
  - 分页栏自身：约 56px
  - 页面边距：约 80px

根据实际页面布局调整减去的像素值。

## 完整示例

### Vue 组件代码

```vue
<template>
  <div>
    <BasicTable @register="registerTable" />
  </div>
</template>

<script lang="ts" setup>
import { BasicTable, useTable } from '/@/components/Table';

const [registerTable] = useTable({
  title: '数据列表',
  api: getDataList,
  columns: [
    {
      title: '时间',
      dataIndex: 'time',
      width: 180,
    },
    {
      title: '设备ID',
      dataIndex: 'deviceId',
      width: 150,
    },
    // ... 其他列
  ],
  useSearchForm: true,
  showTableSetting: true,
  bordered: true,
  // 关键配置
  scroll: {
    x: 1200,  // 当列宽总和超过1200px时出现横向滚动
    y: 'calc(100vh - 300px)',  // 固定表格内容区高度
  },
  pagination: {
    pageSize: 100,
    pageSizeOptions: ['10', '50', '100', '500', '1000'],
  },
});
</script>
```

### 响应式高度调整

针对不同场景，可以调整高度计算方式：

```javascript
// 场景1：有顶部导航和查询表单
scroll: { y: 'calc(100vh - 300px)' }

// 场景2：全屏表格，只有顶部导航
scroll: { y: 'calc(100vh - 120px)' }

// 场景3：固定像素高度
scroll: { y: 500 }

// 场景4：嵌套在其他容器中
scroll: { y: 'calc(100% - 100px)' }
```

## 常见问题

### Q1: 设置后表格高度太小/太大？

**解决方法**：调整 calc 中减去的像素值
```javascript
// 根据实际页面元素高度调整
scroll: { y: 'calc(100vh - 250px)' }  // 减小数值，表格更高
scroll: { y: 'calc(100vh - 400px)' }  // 增大数值，表格更矮
```

### Q2: 不同分辨率下显示不一致？

**解决方法**：使用相对单位而非固定像素
```javascript
// 推荐：使用 vh 单位
scroll: { y: 'calc(100vh - 300px)' }

// 不推荐：固定像素
scroll: { y: 600 }  // 在小屏幕上可能太高
```

### Q3: 横向内容被截断？

**解决方法**：同时设置 scroll.x
```javascript
scroll: {
  x: 1500,  // 或 'max-content'
  y: 'calc(100vh - 300px)'
}
```

## 其他解决方案对比

| 方案 | 优点 | 缺点 | 适用场景 |
|------|------|------|----------|
| **scroll.y（推荐）** | 简单有效，组件原生支持 | 需要计算高度 | 所有场景 |
| CSS Flex 布局 | 纯 CSS 方案 | 对 BasicTable 无效 | 自定义表格组件 |
| 固定定位 | 直观 | 可能造成布局问题 | 简单页面 |
| JavaScript 动态计算 | 精确控制 | 复杂，性能开销 | 特殊需求 |

## 总结

使用 `scroll.y` 配置是解决 Ant Design Vue BasicTable 组件分页栏不固定问题的最佳方案：

1. **简单**：只需一行配置
2. **有效**：立即生效，无需额外代码
3. **兼容**：组件原生支持，无兼容性问题
4. **响应式**：使用 calc() 自适应不同屏幕

记住核心原则：**设置 scroll.y 让表格内容区域成为固定高度的滚动容器，分页栏自然固定在底部。**
