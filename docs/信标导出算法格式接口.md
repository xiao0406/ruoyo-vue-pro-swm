# 信标导出算法格式接口

## 接口概述

导出信标数据用于算法定位，接口按楼层ID分组返回信标信息，MAC地址格式为小写带冒号分隔。

## 接口信息

| 属性 | 值 |
|------|-----|
| 请求方式 | GET |
| 请求路径 | `/swm/swmBeaconStation/exportAlgorithmFormat` |
| 数据格式 | JSON |

## 请求参数

无请求参数（自动按当前登录用户所属租户过滤数据）

```json
        "location": "研究院1楼测试2",

        "y": 3000,
        "floorId": "100001"
      }
    },
    "100002": {
      "80:ec:cc:d2:11:c5": {
        "location": "研究院2楼测试3",
        "x": 2000,

        "floorId": "100002"
      }

```

### 场景2：存在无 floorId 的信标（归入默认分组）

当存在无 floorId 的信标时，这些信标会被归入一个默认分组，分组的 floorId 取自 `swm_site_map_management` 表中 `status='0'`、顶级地图节点（`parent_id='0'`）的第一条记录的 id。location 字段固定输出为"全景地图信标"。

假设 `defaultFloorId = '200001'`，信标数据如下：

| beaconId | floorId | location |
|----------|---------|----------|
| 80ECCCD23F2F | 100001 | 研究院1楼测试1 |
| 80ECCCD23F30 | 100001 | 研究院1楼测试2 |
| 80ECCCD23F40 | *(空)* | 未知位置信标 |

返回 JSON：
```json
{
  "result": "true",
  "msg": "导出成功",
  "data": {
    "100001": {
      "80:ec:cc:d2:3f:2f": {
        "location": "研究院1楼测试1",
        "x": 2000,
        "y": 3000,
        "floorId": "100001"
      },
      "80:ec:cc:d2:3f:30": {
        "location": "研究院1楼测试2",
        "x": 2500,
        "y": 3000,
        "floorId": "100001"
      }
    },
    "200001": {
      "80:ec:cc:d2:3f:40": {
        "location": "全景地图信标",
        "x": 1500,
        "y": 2000,
        "floorId": "200001"
      }
    }
  }
}
```

### 场景3：无默认分组时的数据

如果 `swm_site_map_management` 表中没有符合条件的地图记录（`status='0'`、顶级节点），则无 floorId 的信标不导出。

## 数据结构说明

### 外层结构
- **Key**: 楼层ID（`floorId`）
- **Value**: 该楼层下所有信标的Map

### 内层结构（每个MAC地址对应的数据）
| 字段 | 类型 | 说明 |
|------|------|------|
| location | String | 信标所在位置名称。无 floorId 时固定输出"全景地图信标" |
| x | Number | 图纸像素X坐标 |
| y | Number | 图纸像素Y坐标 |
| floorId | String | 所属楼层ID（无 floorId 的信标使用默认分组的 floorId） |

### MAC地址格式说明
- 数据库存储格式：`80ECCCD23F2F`（12位大写无冒号）
- 接口返回格式：`80:ec:cc:d2:3f:2f`（小写带冒号分隔）

## 数据筛选规则

- 仅返回**常规信标**（信标类型 beaconType = "1"）
- 按当前登录用户所属租户自动过滤

### floorId 分组逻辑

- **有 floorId 的信标**：按各自的 floorId 分组
- **无 floorId 的信标**：归入一个独立分组，分组的 floorId 取自地图表 `swm_site_map_management` 中满足以下条件的记录的 id：
  - `status = '0'`（启用状态）
  - `parent_id = '0'`（顶级地图节点）
  - 属于当前租户
- 如果没有符合条件的地图记录，则无 floorId 的信标不导出

## 前端调用示例

### 1. 新增API方法

```typescript
// 文件：src/api/swm/beacon.ts

/**
 * 导出算法格式数据
 */
export const exportAlgorithmFormat = () =>
  defHttp.get({ url: `${apiPrefix}/exportAlgorithmFormat` });
```

### 2. 按钮调用示例

```typescript
import { exportAlgorithmFormat } from '/@/api/swm/beacon';

// 导出算法格式
async function handleExportAlgorithmFormat() {
  try {
    const res = await exportAlgorithmFormat();
    if (res.result === 'true') {
      // 成功获取数据，可根据需求处理
      // 如：下载JSON文件、预览JSON内容、复制到剪贴板等
      console.log('算法格式数据:', res.data);
    } else {
      message.error(res.msg || '导出失败');
    }
  } catch (error) {
    console.error('导出失败:', error);
    message.error('导出失败，请重试');
  }
}
```

## 注意事项

1. 返回数据量较大时，建议在请求前显示加载状态
2. 数据已按楼层分组，前端可直接使用无需再次处理
3. MAC地址已格式化为小写带冒号格式，无需前端转换
