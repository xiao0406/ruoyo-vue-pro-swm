# 场地底图管理 - 树形结构接口文档

> 后端已完成改造，底图管理支持 **厂区 → 建筑 → 楼层** 三级树形结构。  
> 基础路径：`/swm/swmSiteMapManagement`

---

## 一、数据结构说明

每条记录新增以下字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| `parentId` | string | 父节点ID。**顶层厂区的 parentId 固定为 `"0"`** |
| `mapType` | string | 图纸类型：`factory`=厂区，`building`=建筑，`floor`=楼层 |
| `originPixelX` | int | 图纸起始X像素偏移（这张图左上角在整体坐标系中的X偏移） |
| `originPixelY` | int | 图纸起始Y像素偏移（同上，Y方向） |
| `sortOrder` | int | 同级排序，值越小越靠前 |
| `hasChildren` | boolean | **不是数据库字段**，接口返回时自动计算，表示该节点下面还有没有子节点 |

树形关系举例：
```
华南厂区（factory, parentId="0"）
  ├── A栋办公楼（building, parentId=华南厂区的id）
  │   ├── 1楼（floor, parentId=A栋的id）
  │   └── 2楼（floor, parentId=A栋的id）
  └── B栋仓库（building, parentId=华南厂区的id）
```

> **注意**：厂区和建筑节点可以没有图纸文件（`filePath` 可为空），只作为分组节点存在。

## 二、接口列表

### 1. 查询子节点列表（懒加载，核心接口）

前端点击一个节点时调用，返回该节点下的**直接子节点**。首次进页面传 `parentId=0` 查出所有厂区。

```
GET /swm/swmSiteMapManagement/children?parentId=0
```

**请求参数**：

| 参数 | 必填 | 默认值 | 说明 |
|------|------|--------|------|
| parentId | 否 | `0` | 父节点ID。传 `0` 查厂区，传某个厂区id查它下面的建筑，以此类推 |

**返回示例**：

```json
[
  {
    "id": "abc123",
    "parentId": "0",
    "mapName": "华南厂区",
    "mapType": "factory",
    "projectId": "company001",
    "filePath": null,
    "mapSize": null,
    "scale": null,
    "drawingPixelX": null,
    "drawingPixelY": null,
    "originPixelX": null,
    "originPixelY": null,
    "siteCoordinateXM": null,
    "siteCoordinateYM": null,
    "sortOrder": 1,
    "status": "0",
    "hasChildren": true,
    "remarks": ""
  },
  {
    "id": "xyz789",
    "parentId": "0",
    "mapName": "华北厂区",
    "mapType": "factory",
    "sortOrder": 2,
    "status": "1",
    "hasChildren": false
  }
]
```

> `hasChildren = true` 表示可以继续展开，前端应显示展开箭头。  
> `hasChildren = false` 表示是叶子节点，没有下级了。

### 2. 获取节点详情

点击树节点时，在右侧展示该节点的完整信息。

```
GET /swm/swmSiteMapManagement/detail?id=abc123
```

**请求参数**：

| 参数 | 必填 | 说明 |
|------|------|------|
| id | 是 | 节点ID |

**返回示例**：

```json
{
  "success": true,
  "data": {
    "id": "abc123",
    "parentId": "0",
    "mapName": "华南厂区",
    "mapType": "factory",
    "projectId": "company001",
    "filePath": "{\"url\":\"https://...\",\"fileName\":\"map.png\"}",
    "mapSize": "1920×1080像素",
    "scale": "1:100",
    "drawingPixelX": 1920,
    "drawingPixelY": 1080,
    "originPixelX": 500,
    "originPixelY": 300,
    "siteCoordinateXM": 50.00,
    "siteCoordinateYM": 30.00,
    "sortOrder": 1,
    "status": "0",
    "remarks": "备注信息"
  }
}
```

**节点不存在时**：

```json
{
  "success": false,
  "message": "未找到该节点数据"
}
```

### 3. 保存节点（新增 / 编辑）

新增或编辑一个树节点（厂区 / 建筑 / 楼层），共用同一个接口。

```
POST /swm/swmSiteMapManagement/save
```

**请求参数**：

| 参数 | 必填 | 说明 |
|------|------|------|
| id | 编辑时必填 | 节点ID，新增时不传 |
| parentId | **是** | 父节点ID，新增厂区时传 `"0"` |
| mapName | **是** | 名称，如"华南厂区"、"A栋"、"1楼" |
| mapType | **是** | `factory` / `building` / `floor` |
| projectId | 否 | 所属项目 |
| filePath | 否 | 图纸文件（JSON格式，跟之前上传逻辑一样） |
| mapSize | 否 | 底图尺寸，如 "1920×1080像素" |
| scale | 否 | 比例尺 |
| drawingPixelX | 否 | 图纸X像素 |
| drawingPixelY | 否 | 图纸Y像素 |
| originPixelX | 否 | 起始X像素偏移 |
| originPixelY | 否 | 起始Y像素偏移 |
| siteCoordinateXM | 否 | 场地X坐标(米) |
| siteCoordinateYM | 否 | 场地Y坐标(米) |
| sortOrder | 否 | 排序值，默认0 |
| remarks | 否 | 备注 |

**返回示例**：

```json
{
  "result": "true",
  "message": "保存场地底图管理成功！"
}
```

---

### 4. 删除节点

```
DELETE /swm/swmSiteMapManagement/delete?id=abc123
```

| 参数 | 必填 | 说明 |
|------|------|------|
| id | 是 | 节点ID |

**成功**：
```json
{
  "result": "true",
  "message": "删除场地底图管理成功！"
}
```

**失败（有子节点时拒绝删除）**：
```json
{
  "result": "false",
  "message": "该节点下还有2个子节点，请先删除子节点"
}
```

> ⚠️ 必须从最底层（楼层）开始删，不能直接删有下级的节点。

---

### 5. 启用 / 禁用（不变）

```
POST /swm/swmSiteMapManagement/enable    参数：id, status=0
POST /swm/swmSiteMapManagement/disable   参数：id, status=1
```

### 6. 原有分页列表

```
GET /swm/swmSiteMapManagement/listData
```

原有的分页列表接口，返回所有底图（不分层级）。

**2026-04-07 更新**：每条记录现在也会返回 `hasChildren` 字段，与 `children` 懒加载接口保持一致。

| 字段 | 类型 | 说明 |
|------|------|------|
| `hasChildren` | boolean | `true` = 该节点下还有子节点；`false` = 叶子节点 |

**返回示例**：

```json
{
  "pageNo": 1,
  "pageSize": 10,
  "count": 3,
  "list": [
    {
      "id": "abc123",
      "parentId": "0",
      "mapName": "华南厂区",
      "mapType": "factory",
      "status": "0",
      "hasChildren": true
    },
    {
      "id": "def456",
      "parentId": "abc123",
      "mapName": "A栋办公楼",
      "mapType": "building",
      "status": "1",
      "hasChildren": true
    },
    {
      "id": "ghi789",
      "parentId": "def456",
      "mapName": "1楼",
      "mapType": "floor",
      "status": "1",
      "hasChildren": false
    }
  ]
}
```

## 三、前端对接要点

1. **首次进页面**：调 `children?parentId=0`，拿到所有厂区节点渲染树的第一级
2. **展开节点**：用户点击某厂区/建筑的展开箭头时，调 `children?parentId=该节点id`，拿到下级节点
3. **展开箭头**：根据 `hasChildren` 字段决定是否显示展开箭头
4. **新增节点**：需要传 `parentId`（当前选中的父节点ID）和 `mapType`
5. **mapType 与层级对应**：
   - 在厂区层级下新增 → `mapType = "building"`
   - 在建筑层级下新增 → `mapType = "floor"`  
   - 新增顶层时 → `mapType = "factory"`，`parentId = "0"`
6. **删除限制**：必须先删子节点，不能直接删有下级的节点
