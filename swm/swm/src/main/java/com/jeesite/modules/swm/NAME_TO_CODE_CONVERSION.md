# 名称到编码转换功能实现文档

## 功能概述

本功能实现了人员批量导入时组织架构字段的名称到编码自动转换功能。用户可以在Excel中填写中文名称，系统会自动转换为对应的编码进行存储和验证。

## 实现的解决方案

### 问题背景
- 用户在Excel中填写：`中建钢构广东有限公司`、`二车间`、`二车间二工段`、`二工段`
- 系统需要的是编码：`0001A110000000002ZWA`、`1745709611073945600`、`1775065603265200128`、`1775078204158181376`

### 解决方案
实现了智能名称转换功能，支持：
1. **自动识别格式**：系统能够识别输入的是编码还是名称
2. **自动转换**：将名称自动转换为对应的编码
3. **层级验证**：转换后进行组织架构层级关系验证
4. **详细反馈**：提供转换信息和错误详情

## 修改的文件

### 1. 数据访问层 (DAO)

#### `SwmCommonOptionsDao.java`
- **新增方法**：
  - `getCompanyCodeByName(String companyName)` - 根据公司名称获取编码
  - `getDepartmentCodeByName(String departmentName)` - 根据车间名称获取编码
  - `getProdLineCodeByName(String prodLineName)` - 根据产线名称获取编码
  - `getTeamCodeByName(String teamName)` - 根据班组名称获取编码
  - `getWorkTypeCodeByName(String workTypeName)` - 根据工种名称获取编码
  - `validateDepartmentBelongsToCompany()` - 验证车间是否属于指定公司
  - `validateProdLineBelongsToDepartment()` - 验证产线是否属于指定车间
  - `validateTeamBelongsToProdLine()` - 验证班组是否属于指定产线

#### `SwmCommonOptionsDao.xml`
- **新增SQL查询**：
  - 名称到编码的映射查询

### 2. 服务层 (Service)

## 核心功能流程

### 1. 导入流程
```
Excel文件 → 读取数据 → 基础验证 → 名称转换 → 业务验证 → 层级验证 → 保存数据
```

### 2. 转换流程
```
检测字段格式 → 查询数据库映射 → 返回转换结果 → 记录转换信息
```

### 3. 验证流程
```
转换后编码 → 数据库层级查询 → 验证关系 → 返回验证结果
```

## 使用说明

### 1. 数据准备
- 支持名称格式：`中建钢构广东有限公司`
- 支持编码格式：`0001A110000000002ZWA`
- 支持混合格式：部分字段名称，部分字段编码

### 2. 导入结果
- **成功**：数据正确导入，显示成功条数
- **转换**：名称自动转换为编码，显示转换条数
- **错误**：详细错误信息，精确到行和字段

### 3. 错误处理
- 名称不存在：提示找不到对应编码
- 层级关系错误：提示具体的关系问题
- 格式错误：提示数据格式问题
