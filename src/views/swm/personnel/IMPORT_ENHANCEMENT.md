# 人员批量导入功能增强

## 功能概述

本次开发主要增强了人员批量导入功能，支持"是否场内员工"字段的控制，并实现了组织架构字段的级联验证。

## 主要改进

### 1. 新增字段支持

- **是否场内员工**：必填字段，支持"是/否"或"1/0"格式
- **组织架构字段**：所属单位、所属车间、所属产线、所属班组、所属工种

### 2. 智能字段控制

- 当"是否场内员工"选择"是"时：
  - 组织架构字段变为必填
  - 系统验证字段级联关系
  - 验证数据有效性
- 当"是否场内员工"选择"否"时：
  - 组织架构字段被自动清空
  - 即使用户填写了也会被忽略

### 3. 增强的验证机制

- **基础字段验证**：姓名、身份证号码、手机号码格式验证
- **级联关系验证**：单位 → 车间 → 产线 → 班组的层级关系验证
- **工种验证**：验证工种是否存在于系统中
- **重复检查**：身份证号码重复检查

### 4. 改进的用户体验

- **增强版模板**：包含所有组织架构选项数据
- **详细错误提示**：具体到行和列的错误信息
- **分步验证**：客户端预验证 + 服务端验证
- **友好的界面**：清晰的字段说明和操作提示

```
1. 文件上传 → 解析Excel数据

5. 保存数据 → 写入数据库
6. 结果反馈 → 详细的成功/失败报告
```

## 使用说明

### 1. 下载模板

- 点击"下载模板"按钮
- 获取包含组织架构选项的 Excel 模板
- 支持降级到基础版模板

### 2. 填写数据

- 按照模板格式填写数据
- 注意"是否场内员工"字段的影响
- 从提供的选项中选择组织架构信息

### 3. 导入数据

- 上传填写好的 Excel 文件
- 系统自动验证数据
- 查看详细的导入结果

### 4. 错误处理

- 查看详细错误信息
- 按照提示修正数据
- 支持部分成功导入

## 注意事项

1. **数据准确性**：确保组织架构数据与系统中的选项匹配
2. **格式要求**：严格按照模板格式填写数据
3. **重复检查**：身份证号码不能重复
4. **级联关系**：组织架构字段必须符合层级关系
5. **字段控制**：根据"是否场内员工"正确填写相关字段
